# 🎉 Site Festa Junina

Projeto desenvolvido com **HTML5 e CSS3**, com o objetivo de apresentar a cultura e as tradições das festas juninas brasileiras por meio de uma página web.

🌐 **Acesse o projeto:** [Site Festa Junina](https://leonardo-dominic.github.io/site-festa-junina/)

## 📌 Sobre o projeto

O site apresenta informações sobre uma das celebrações culturais mais tradicionais do Brasil, destacando suas características, costumes e elementos típicos.

O projeto foi desenvolvido como uma oportunidade de praticar conceitos fundamentais de desenvolvimento web, organização de arquivos e estilização de páginas.

## ✨ Funcionalidades

- **Página inicial:** apresentação do tema Festa Junina.
- **Sobre:** introdução à história e à importância cultural da celebração.
- **Galeria de fotos:** imagens relacionadas às festividades.
- **Calendário:** representação do mês de junho de 2027.
- **Tradições:** informações sobre quadrilha, comidas típicas, fogueiras e brincadeiras.
- **Avaliação:** formulário com identificação do usuário e avaliação por estrelas.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação do conteúdo.
- CSS3 — estilização e organização visual da página.
- GitHub Pages — hospedagem e publicação do projeto.
